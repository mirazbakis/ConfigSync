# ConfigSync

An on-device iOS application built to generate, preview, and export custom Apple Configuration Profiles (`.mobileconfig`) directly on iPhone and iPad.

## Features

* **On-Device Profile Generation:** Build restriction `.mobileconfig` files entirely offline in device memory—no external servers, APIs, or PC software required.
* **Live XML Preview:** Inspect structured XML plist payloads in real time before exporting.
* **Native Export:** Export the mobileconfig directly to your Files for downloading.
* **Device Customizations:** Choose from many tweaks built into ConfigSync.
